# 09 — คู่มือและกฎเหล็กการพัฒนาสำหรับ AI Engineer (Development Protocol)

---

## กฎเหล็กการพัฒนา (AI Rules of Engagement)
1. Deterministic Calculation: AI สกัดเฉพาะตัวเลขและรหัสจากแบบ การคิดคำนวณทั้งหมดต้องทำใน Python Script
2. Autonomous Execution: เมื่อได้รับคำสั่งยืนยัน ให้ดำเนินการทุกขั้นตอนรวดเดียวจบจนเสร็จสมบูรณ์ 100% โดยไม่ต้องหยุดถาม
3. No Cross-Contamination: ห้ามนำข้อมูลระหว่างโฟลเดอร์โครงการมาปะปนกันเด็ดขาด
4. Clean Code & Docs Integrity: รักษาโครงสร้างโค้ดและไฟล์ประวัติ LOG.md ให้เป็นปัจจุบันเสมอ
