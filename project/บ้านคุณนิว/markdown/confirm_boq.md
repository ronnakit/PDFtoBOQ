## 3. คาน (Beam, B1-B6) — ✅ ครบแล้ว (38 segment, ยืนยันโดยเจ้าของโปรเจกต์)

**ที่มาข้อมูล:** `extract_beam_boq.py` อ่าน S-02 (แบบแปลนคานคอดิน+พื้น) ด้วย Sonnet 5 ผ่าน API ได้ 28 segment ที่มั่นใจ + อีก 7 segment ที่โมเดลเองปฏิเสธจะเดา (กระจุกห้องมุม SW: แถว C-D-E, คอลัมน์ 1-4) — แก้ด้วยการซูมมือ 500dpi เฉพาะจุด SW cluster พร้อมแกนกริดในภาพเดียวกัน ได้ผลลัพธ์ชุดแรก 39 segment แต่ **เจ้าของโปรเจกต์ตรวจพบว่าจุดเดียว (แถว D-E คอลัมน์1) อ่านผิด** — ผมเข้าใจผิดว่าเส้นแบ่งระบบพื้น "2.80" เป็นคานตัดแบ่งความสูง ทั้งที่จริงแนวตั้ง (B3, B2, B3) วิ่งเต็มช่วง D-E 4.50ม.ทั้งหมด และคานสั้น 2.00ม.ที่ตำแหน่งนั้นคือ **B1** ไม่ใช่ B2 — แก้ตามที่เจ้าของโปรเจกต์ยืนยันแล้ว รวม **38 segment ครบทุกเส้นที่ระบุรหัสได้บนแปลน** ต้นทุน API รวม ~4 บาท (การแก้ไขทั้ง 2 รอบเป็นการคำนวณซ้ำด้วยโค้ด ไม่เรียก API ซ้ำ)

**ข้อมูลอ้างอิงที่ใช้คำนวณ (ยืนยันแล้วจาก S-08 — 100% เชื่อถือได้ อ่านตารางไม่ใช่นับกริด):**
- คาน B1-B6 ทุกตัวหน้าตัดเท่ากัน **0.20×0.40 ม.**
- เหล็กยืน/ปลอกแต่ละรหัส: B1(2-DB12 top/bottom, 1-RB6@0.15), B2(2-DB12 top/4-DB12 bottom, 1-RB6@0.15), B3(2-DB12 top/bottom +1-DB12 ADD., 1-RB6@0.15), B4(2-DB12 top/3-DB12 bottom +2-DB12 ADD., 1-RB6@0.15), B5(3-DB16 top/bottom +2-DB16 ADD., 1-RB6@0.15), B6(6-DB16 top/bottom, 2-RB6@0.15)
- **เหล็ก "ADD." ยาว = L/4 ของความยาวคานเส้นนั้นเอง** (คนละค่าต่อ segment แม้รหัสเดียวกัน)
- กติกาที่ใช้เติมความยาวช่วง SW cluster: **ความยาวคานแนวตั้ง (เสาเข็มขัดรอบห้อง) = ความยาวช่วงแถว (row span) เสมอ ไม่ขึ้นกับว่าอยู่คอลัมน์ไหน** เพราะแนวตั้งวิ่งเต็มความสูงบ่อนั้นเสมอ — ใช้หลักการนี้แก้ปมที่ตำแหน่งคอลัมน์แม่นยำอ่านยากแต่ความสูงช่วงแถวรู้แน่นอนอยู่แล้ว

## 8. คานคอดินลอยใต้ทางลาดคนพิการ (2569-08-31) — ✅ ปิดเคสสุดท้ายของหมวดโครงสร้าง

**ที่มา:** แบบ A-01 (ผังบริเวณ) แสดงทางลาดโค้งสำหรับผู้พิการ (มุมบ้าน ใกล้ที่จอดรถ) — ยืนยันจากเจ้าของโปรเจกต์ว่าเป็นจุดเดียวในโครงการที่คานคอดินลอยสูงจากพื้นดินเดิม ต้องมีผนังก่ออิฐเต็มแผ่น+ฐานเล็กรองรับ ตามแบบขยายทั่วไปใน S-09 (ไม่มีแบบขยายจริงเฉพาะจุดนี้ตอนก่อสร้าง)

**⚠️ แบบ A-01 ไม่มีตัวเลขความยาวทางลาดกำกับเลย (เป็นเส้นโค้ง วัดจากภาพสแกนไม่ได้แม่นยำ)** — เจ้าของโปรเจกต์ให้คำนวณย้อนกลับจากกฎหมายแทนที่จะวัดจากแบบ:
- **ความสูง = 1.2 ม.** (ค่าเดียวกับที่ใช้กับตอม่อทั้งโครงการ — ระดับดินเดิม/ถนน/พื้นบ้านเฉลี่ยเท่ากันทั้งไซต์)
- **ความลาดชันตามกฎหมาย ≤ 1:12** (กฎกระทรวงกำหนดสิ่งอำนวยความสะดวกในอาคารสำหรับคนพิการ/คนชรา — ยืนยันด้วย WebSearch) → **ความยาวทางลาด = 1.2×12 = 14.4 ม.**
- ใช้ความสูงคงที่ตลอดความยาว ไม่ลดตามความชันจริงของทางลาด (ตามที่เจ้าของโปรเจกต์ระบุว่าไม่คุ้มเวลาคิดละเอียดสำหรับรายการเล็กขนาดนี้)

| รายการ | ปริมาณ |
|---|---|
| ผนังก่ออิฐเต็มแผ่น (14.4×1.2ม.) | **17.28 ตร.ม.** |
| คอนกรีตฐานเล็กรองรับ (14.4×0.35×0.12ม., ขนาดฐานตาม S-09) | **0.605 ม³** |
| เหล็กหนวดกุ้ง DB9@0.20ม. | 72 เส้น (ความยาว/เส้นยังไม่ยืนยัน — รู้แค่ระยะห่างจากแบบ S-09 ไม่กระทบยอดรวมมาก) |

## 9. โครงสร้างหลังคา (Roof Structure) — ✅ ครบแล้ว (2569-09-01) — ปิดเคส "หมวดโครงสร้าง" จริงๆ

> **บริบท:** ตอนแรกเข้าใจผิดว่า "หมวดโครงสร้าง Stage 2 ครบ 100%" ไปแล้วโดยลืมหมวดนี้ — โครงสร้างหลังคาเป็น**รายการเดียวที่ใหญ่ที่สุด**ในหมวดโครงสร้างทั้งหมดตาม ground-truth BOQ (553,464 บาท) ดูที่มาการค้นพบข้อผิดพลาดนี้ใน [LOG.md](../../LOG.md) และกฎใหม่ที่เพิ่มเพื่อกันพลาดซ้ำใน [03-ai-boq-procedure.md](../../03-ai-boq-procedure.md)

**ที่มาข้อมูล:** `extract_roof_boq.py` — เรขาคณิตทั้งหมดยืนยันจากเจ้าของโปรเจกต์โดยตรง (ไม่ใช่ AI อ่านจาก S-03/S-04 เอง เพราะพิสูจน์แล้วว่าอ่านตำแหน่งเส้นทแยง/ระยะบนแบบสแกนความหนาแน่นสูงแบบนี้ไม่แม่นยำ — ต้องถามยืนยันเป็นรอบๆ จนตรงกับโมเดล SketchUp จริงของเจ้าของโปรเจกต์) คำนวณด้วยโค้ด Python ล้วน

**เรขาคณิตที่ยืนยันแล้ว:**
- ระดับ: อกไก่ +7.05ม., อะเส +4.75ม. → ยกตัว (rise) 2.30ม., มุมเอียง = arctan(2.30/4.50) = **27.072°** (run 4.50ม. จากคอลัมน์1→2, ไม่รวมชายคายื่น) ใช้มุมเดียวกันทั้งหลัง
- เป็น**จั่วเต็มความยาว 2 หลังมาชนกัน** (ไม่ใช่หลังคาทรงปั้นหยาเต็มรูปแบบ): จั่วหลัก (สันที่คอลัมน์2, จั่วธรรมดาทั้ง 2 ปลาย เหนือ-ใต้) + จั่วปีกส่วนต่อ (สันที่กึ่งกลางแถว A-B, จั่วธรรมดาทั้ง 2 ปลาย ตะวันตก-ตะวันออก)
- **ตะเข้เกิดจุดเดียว** ที่โซนคอลัมน์2 ถึง (คอลัมน์4-1.0ม.ชายคายื่น)=8.0ม., แถว A-B — ยืนยันตัวเลข 3.5ม.จากคอลัมน์2 ตรงกับโมเดล SketchUp เป๊ะ (=col4-1.0-col2)
- ชายคายื่น: ทิศคอลัมน์ 1.0ม., ทิศแถว 1.2ม. (ใช้ทั้งหลังสม่ำเสมอ)
- ไม่รวม แผ่นมุงหลังคา (CPAC Monier) และ เชิงชายชัวร์ SCG — เป็นงานสถาปัตย์/finish ตามที่ตกลงไว้

**ผลคำนวณ:**

| รายการ | สเปคเหล็ก | จำนวน | ความยาวรวม |
|---|---|---|---|
| จันทัน | C 100x50x20x2.3 @1.00ม. | 47 ชิ้น | 220.83 ม. |
| ตะเข้ราง (valley) | 2-C 150x50x20x2.3 | 2 ชิ้น | 9.35 ม. |
| อกไก่ | 2-C 100x50x20x2.3 | — | 28.90 ม. (จั่วหลัก 17.90 + จั่วปีกส่วนต่อ 11.00) |
| ดั้ง | 2-C 150x50x20x2.3 @1.00ม.ตามแนวอกไก่ | 31 ชิ้น | — (สมมติสูง=rise=2.30ม.ทุกต้น ยังไม่ยืนยัน) |
| อะเส | 2-C 150x50x20x2.3 | — | 39.90 ม. (เฉพาะขอบชายคายาวที่จันทันวางพาด ไม่รวมผนังหน้าจั่ว) |
| ระแนง | กล่อง 25x25x1.6 @0.32ม. | — | ~639.52 ม. (ประมาณจากพื้นที่ลาดเอียง 204.65 ตร.ม. ÷ 0.32ม. — วิธีลัด ไม่ได้นับแนวจริงทีละเส้น) |

**Cutting list (สต๊อก 6.0ม., ยืนยันจากเจ้าของโปรเจกต์) — คิดแบบ FFD ทีละชิ้นจริง ไม่ใช่หารความยาวรวม:**

| กลุ่มเหล็ก (สต๊อกแยกชิ้นกัน) | รายการ | ชิ้น/ท่อนที่ต้องซื้อ | ของเสีย |
|---|---|---|---|
| 2-C150x50x20x2.3 | อะเส (ต่อจากสต๊อก 3 เส้น: 17.9+11.0+11.0ม.) + ดั้ง (31×2.30ม.) รวมแพ็คด้วยกัน | **23 ท่อน** (138.0ม.) | 19.4% |
| 2-C100x50x20x2.3 | อกไก่ (ต่อจากสต๊อก 2 เส้น: 17.9+11.0ม.) | **5 ท่อน** (30.0ม.) | 3.7% |
| C100x50x20x2.3 (เดี่ยว) | จันทัน 28/47 ชิ้นที่ยาวไม่เกิน 6ม. | **26 ท่อน** (156.0ม.) | 33.7% |
| กล่อง25x25x1.6 | ระแนง | ยังทำไม่ได้ (มีแต่ความยาวรวมประมาณ ไม่มีความยาวทีละเส้น) | — |

**⚠️ จันทัน 19/47 ชิ้น (ฝั่งตะวันตกของจั่วหลัก) ยาว 6.177ม. — เกินสต๊อก 6.0ม.เล็กน้อย** ไม่รวมในตาราง cutting-list ข้างบน เพราะรอยต่อกลางช่วงจันทันไม่เหมาะทางโครงสร้าง (จันทันรับแรงดัดเต็มช่วง) — ต้องสั่งสต๊อกยาวพิเศษ (~6.2ม.) หรือตัดจากสต๊อก 12ม.แทน เป็นจุดที่ต้องตัดสินใจหน้างานจริง ไม่ใช่แค่คำนวณเลข

**⚠️ การเทียบกับ BOQ จริง/โมเดล 3D — ไม่ใช้เป็นการยืนยัน:** เจ้าของโปรเจกต์ส่งไฟล์ 3D component export (`newhouse เหล็กหลังคา.xlsx`) มาเทียบ แต่ยืนยันว่า**หลังคาที่สร้างจริงเป็นคนละแบบ** (เปลี่ยนเป็นเมทัลชีท เอาเหล็กไปทำโรงจอดรถต่อ) — ไม่ใช่การตรวจสอบ ground-truth ที่ใช้ได้ ตัวเลขในตารางข้างบนอิงตามเรขาคณิต**ที่ระบุใน S-03/S-04 เท่านั้น** (การออกแบบดั้งเดิม ก่อนแก้ไขหน้างาน)

**⚠️ ยังไม่ยืนยัน/ยังไม่ถอด:**
- ความสูงจริงของดั้งแต่ละต้น (สมมติ=2.30ม.คงที่ทุกต้น ยังไม่ตรวจสอบว่าดั้งวางบนอะไร)
- ระแนง คำนวณแบบลัด (พื้นที่÷ระยะห่าง) ยังไม่นับแนวจริงทีละเส้น
- อะเส เฉพาะขอบชายคายาว ไม่รวมผนังหน้าจั่ว (สมมติว่าจันทันไม่วางพาดที่ผนังหน้าจั่ว)
- เชิงชายชัวร์ SCG (5.6 ใน BOQ จริง) — สถานะในสโคป (งานสถาปัตย์/finish) ยังไม่ได้ถามเจ้าของโปรเจกต์ตรงๆ
