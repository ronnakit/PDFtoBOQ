# PDFtoBOQ — ภาพรวมโครงการ

> **ชื่อโครงการ/แอป: "PDFtoBOQ"** (ตัดสินใจแล้ว 2569-09-02 — ดู [BACKLOG.md](./BACKLOG.md)) **ชื่อ "ไพน้อย (Py-Noi)" คือชื่อ AI agent ที่ทำหน้าที่ถอดแบบ/ประเมินราคาภายในแอป ไม่ใช่ชื่อแอป** — เทียบเท่ากับที่โครงการรักบ้านมี AI assistant ชื่อ "มะลิ" แต่ตัวโครงการชื่อ "รักบ้าน"

## 1. โครงการนี้คืออะไร

แพลตฟอร์มที่แปลงไฟล์แบบ CAD (DWG/DXF) ให้เป็น **BOQ (Bill of Quantities)** โดยอัตโนมัติด้วย AI agent ชื่อ **"ไพน้อย"** ลดเวลาการถอดแบบและประเมินราคาสำหรับผู้รับเหมาไทยรายเล็ก-กลาง (งานมูลค่า < 10 ล้านบาท, พื้นที่ < 200 ตร.ม.)

## 2. ความสัมพันธ์กับโครงการรักบ้าน@CNX

**นี่ไม่ใช่โครงการแยกจากรักบ้าน — เป็น MVP ที่เร็วกว่า nested อยู่ในเครือเดียวกัน** เหตุผลที่เกิดโครงการนี้ขึ้นมา:

- โครงการรักบ้าน (ดู `D:\dev\rakbaan_md\`) เป็น two-sided marketplace เต็มรูปแบบ ต้องมีเครือข่ายช่าง ประกัน Payment Gateway ฯลฯ — breakeven อยู่ปีที่ 2-3 ตาม `04-business-model-finance.md` ของรักบ้าน ถือว่านานเกินไปกว่าจะพิสูจน์ได้ว่าหาเงินจริงได้
- Core engine ของโครงการนี้ ("ไพน้อย" ถอดแบบ CAD → BOQ) **คือของเดียวกัน** กับฟีเจอร์ "AI Auto-BOQ Generator" ที่รักบ้านสัญญาไว้ใน [02-app-features-ui.md §5.3](file:///D:/dev/rakbaan_md/02-app-features-ui.md) ของรักบ้าน
- กลยุทธ์: สร้างและขายโครงการนี้เป็น B2B SaaS แยกก่อน (single-sided, ไม่ต้องมีเครือข่ายช่าง/ประกัน) เพื่อพิสูจน์ความแม่นยำของ AI Auto-BOQ และสร้างรายได้จริงเร็วกว่ามาก แล้วค่อยผนวก dataset/engine เดียวกันเข้า Data Flywheel ของรักบ้านตอนถึง phase ก่อสร้าง/รีโนเวท
- แนะนำวางตำแหน่งเป็น **sister product ใต้ RPS Group** ไม่ใช่คู่แข่งหรือเบี่ยงเบนออกจากรักบ้าน

## 3. Mission

พัฒนาแพลตฟอร์มที่เปลี่ยนไฟล์แปลน CAD ให้เป็น BOQ (และในระยะถัดไปคือโมเดล 3D) ได้โดยอัตโนมัติ เพื่อลดเวลาถอดแบบและประเมินราคาสำหรับผู้รับเหมาไทย

## 4. Target Personas

| Persona | ลักษณะ | Pain Point |
|---|---|---|
| ผู้รับเหมารุ่นใหม่ (คุณกร) | อยากปิดการขายไว แม่นยำเรื่องต้นทุน ไม่เสียเวลาเอกสาร | เบื่อถอดแบบมือ/Excel กลัวคำนวณพลาดจนเข้าเนื้อ |
| รูปแบบโครงการ | บ้านจัดสรร, ทาวน์โฮม, อาคารพาณิชย์ (< 200 ตร.ม.) | ต้องการความแม่นยำ + ความโปร่งใสราคา (อิงราคากลางภาครัฐ) |
