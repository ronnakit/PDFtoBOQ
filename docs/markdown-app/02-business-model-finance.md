# โมเดลธุรกิจและการเงิน (Illustrative — ยังไม่มีตัวเลขต้นทุนจริง)

> ⚠️ ตัวเลขทั้งหมดในเอกสารนี้เป็นกรอบแนวคิดเบื้องต้น (Illustrative) ยังไม่มีข้อมูลต้นทุน compute/hosting จริง หรือผลทดสอบ willingness-to-pay จากลูกค้าจริง — ห้ามใช้นำเสนอนักลงทุนโดยไม่ตรวจทานก่อน ดู [BACKLOG.md](./BACKLOG.md)

## 1. โมเดลรายได้ (3 ระยะ เรียงตามความเร็วในการสร้างรายได้)

| ระยะ | โมเดล | คำอธิบาย | ความเร็วสร้างรายได้ |
|---|---|---|---|
| 1. Concierge MVP | บริการมนุษย์ช่วย AI | ลูกค้าส่งไฟล์ DWG → "ไพน้อย" ร่าง BOQ → ทีมเราตรวจ/แก้ → ส่งกลับเป็น Excel ภายใน 24-48 ชม. ตั้งราคาต่อหลัง (เช่น 1,500-3,000 บาท/หลัง — ✅ ตรวจสอบกับราคาตลาดจริงแล้ว 2569-08-26: ฟรีแลนซ์รับถอดแบบ BOQ จริงคิด 10-15 บาท/ตร.ม. หรือ 5+5+5 บาท/ตร.ม. แยกโครงสร้าง/สถาปัตย์/ระบบ — สำหรับบ้าน < 200 ตร.ม. (ตรง target persona พอดี) คิดเป็น ~2,000-3,000 บาท **ตรงกับตัวเลข illustrative เดิมพอดี** ดู [01-market-competitors.md §1.1](./01-market-competitors.md)) | เร็วที่สุด — ไม่ต้องรอ automation สมบูรณ์ |
| 2. Self-serve credit | Pay-per-use | ลูกค้าอัปโหลดเอง เติมเครดิต (500/1,000/2,000 บาท) ระบบประมวลผลอัตโนมัติไม่ต้องมีคนตรวจ | ปานกลาง — ต้อง parser แม่นพอจะไม่ต้องมีคนตรวจ |
| 3. Subscription | รายเดือน/รายปี | สำหรับผู้รับเหมาที่ทำหลายโปรเจกต์/เดือน ต้องการรายได้ประจำ (recurring) — มี comp ราคาจริงแล้ว: คู่แข่งไทย Phayoo Estimating คิด **500 บาท/โครงการ/เดือน** สำหรับเครื่องมือวัด+ผูก formula คล้ายกันมาก ดู [01-market-competitors.md §1.1](./01-market-competitors.md) | ช้าที่สุด — ต้องมีฐานลูกค้าประจำก่อน |
| 4. CAD Cleanup Fee | ค่าบริการเพิ่มเติม | ถ้า Drawing Readiness Report (ดู [07-drawing-signal-vs-noise.md §8-9](./07-drawing-signal-vs-noise.md#8-ผลกระทบต่อ-sop-เดิม)) พบว่าไฟล์สกปรก/เลเยอร์ไม่มีมาตรฐานเกินเกณฑ์ เสนอบริการแก้ไข/จัดระเบียบแบบก่อนถอดแบบเป็นรายการแยก | เร็ว — ต้นทุนต่ำเพราะระบบตรวจจับปัญหาให้อัตโนมัติอยู่แล้ว ขายเป็น upsell ในทุกไฟล์ที่ไม่ผ่านเกณฑ์ |

**คำแนะนำ:** เริ่มที่ระยะ 1 ก่อนเสมอ เพราะพิสูจน์ willingness-to-pay ได้จริงโดยไม่ต้องรอ engineering เสร็จสมบูรณ์ (แนวทาง "ทำสิ่งที่ไม่ scale ก่อน" แบบ YC) ค่อยไล่ automate เป็นระยะ 2-3

## 2. Freemium tier

- ฟรีสำหรับอาคารพื้นที่ < 200 ตร.ม. (ตามร่างเดิม) — ⚠️ ต้องคิดให้ดีว่าฟรีเทียร์นี้จะกิน segment เป้าหมายทั้งหมดไปหรือเปล่า (เพราะ target persona คือบ้าน/อาคารพาณิชย์ < 200 ตร.ม. พอดี) อาจต้องปรับเป็น "ฟรีครั้งแรก N ไฟล์" แทน "ฟรีตามขนาดพื้นที่" — เป็น open decision ดู [BACKLOG.md](./BACKLOG.md)

## 3. โครงสร้างต้นทุน (กรอบคิด — ตัวเลขจริงยังไม่มี)

| หมวด | รายการ | สถานะ |
|---|---|---|
| Compute ต่อไฟล์ | parsing (ezdxf) + API call ราคา + generate Excel | ⬜ ยังไม่วัด |
| Hosting เว็บแอป + server-side core | ค่า server รายเดือน | ⬜ ยังไม่เลือก provider (ดู [05-technical-architecture.md](./05-technical-architecture.md)) |
| ค่าแรงคนตรวจ (Concierge phase) | QS ตรวจ/แก้ BOQ ต่อไฟล์ | ⬜ ยังไม่ประเมินเวลาเฉลี่ยต่อไฟล์ |
| การตลาด/distribution | คอนเทนต์ + กลุ่ม Facebook/LINE ผู้รับเหมา | ⬜ ยังไม่เริ่ม |

## 4. เทียบกับรักบ้าน — ทำไมงบลงทุนต่ำกว่ามาก

ต่างจากรักบ้านที่ต้องใช้ Seed 8-12 ล้านบาท (ต้องจ่ายเครือข่ายช่าง/ประกัน/PG) โครงการนี้เป็น **B2B SaaS ฝั่งเดียว** — ต้นทุนหลักคือเวลา dev ไม่ใช่เงินก้อนใหญ่ บูตสแตรปได้จริงโดยไม่ต้องระดมทุนก่อน

**มูลค่าเชิงกลยุทธ์ที่สำคัญกว่าตัวเงิน:** traction จากโครงการนี้ (ลูกค้าจ่ายเงินจริง, ความแม่นยำที่พิสูจน์แล้ว) ใช้เป็นหลักฐานเสริม pitch ของรักบ้านตอนระดมทุน Seed ได้ — เปลี่ยนจาก "เราจะทำ AI Auto-BOQ" เป็น "เรามี AI Auto-BOQ ที่ขายจริงแล้ว"
